# RF Measurement Framework Documentation

This directory contains the design specification for an open-source
Python project tentatively named `rfmeasurement`.

Start with [index.md](index.md).

The documents are intended to evolve alongside the public repository.
They are not immutable requirements; scientific evidence, prototypes,
user feedback and upstream ecosystem changes should be used to revise
them.

## Current principle

> **A trustworthy RF result should carry its validation, uncertainty and
> provenance with it.**
