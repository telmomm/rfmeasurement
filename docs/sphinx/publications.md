# Publications using or citing rfmeasurement

The `rfmeasurement` project itself is a young, design-stage project (see the
{doc}`training/roadmap`). Generating this kind of evidence of research use
is itself part of the project's plan toward a {doc}`training/joss-strategy`
and its {doc}`training/research-plan`.

## Projects using rfmeasurement

- [nanovna-calibration](https://github.com/telmomm/nanovna-calibration) --
  a reproducible NanoVNA one-port SOL calibration workflow. Uses
  `rfmeasurement` for measurement context, validation, and provenance
  alongside `scikit-rf`. Archived on Zenodo:
  [10.5281/zenodo.22722703](https://doi.org/10.5281/zenodo.22722703). An
  associated paper is currently in review; its DOI will be added here once
  available.

## Package indexes

Automated package indexes that have picked up `rfmeasurement` from PyPI.
These reflect indexing, not evaluated scientific use, and are listed
separately from the projects above:

- [pydigger-data](https://github.com/szabgab/pydigger-data) -- data
  collected by the [PyDigger](https://pydigger.code-maven.com/) PyPI package
  crawler.

If you have used `rfmeasurement` in a paper, thesis, preprint, or laboratory
workflow, please let us know by opening an
[issue](https://github.com/telmomm/rfmeasurement/issues) or a pull request
adding it to this page -- it will be listed here.
